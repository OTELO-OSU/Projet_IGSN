# Deploy variables

- Generated by `make env-docs` from `infra/scripts/compose-env.ts`, never edit by hand.
- Define each on GitLab as [deploy.md](deploy.md#defining-the-variables-in-gitlab) explains.

| Name                              | Required                 | Kind     | Example                                                                                  | Purpose                                                                                                                       |
| --------------------------------- | ------------------------ | -------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `IMAGE_PREFIX`                    | yes                      | pipeline | `registry.example.org/group/project`                                                     | Registry path of the images, `$CI_REGISTRY_IMAGE`.                                                                            |
| `IMAGE_TAG`                       | yes                      | pipeline | preproduction: `preprod-<short sha>`<br>production: `v1.2.3`                             | Tag of the images to run.                                                                                                     |
| `HTTP_PORT`                       | yes                      | variable | preproduction: `8081`<br>production: `8080`                                              | Host port Caddy publishes for the infra team's TLS proxy, distinct per environment on the shared host.                        |
| `DOMAIN`                          | yes                      | variable | `<domain>`                                                                               | Apex domain: the stack is served at https://igsn.$DOMAIN.                                                                     |
| `DATABASE_NAME`                   | yes                      | variable | `igsn`                                                                                   | Database name.                                                                                                                |
| `DATABASE_USER`                   | yes                      | variable | `igsn`                                                                                   | Database user, owner of the schema.                                                                                           |
| `DATABASE_PASSWORD`               | yes                      | secret   |                                                                                          | Database password.                                                                                                            |
| `DATABASE_POOL_MAX`               | no                       | variable |                                                                                          | Most connections the api opens to Postgres; set it to about the database's CPU count, unset keeps postgres.js's 10.           |
| `SMTP_HOST`                       | yes                      | variable |                                                                                          | Outbound mail relay; the api refuses to boot without it.                                                                      |
| `SMTP_PORT`                       | no                       | variable | `587`                                                                                    | Relay port; 465 switches to implicit TLS.                                                                                     |
| `SMTP_USER`                       | no                       | variable |                                                                                          | Relay user; empty means no authentication.                                                                                    |
| `SMTP_PASSWORD`                   | with `SMTP_USER`         | secret   |                                                                                          | Relay password.                                                                                                               |
| `SMTP_FROM`                       | no                       | variable |                                                                                          | From address of every mail.                                                                                                   |
| `SMTP_FROM_NAME`                  | no                       | variable |                                                                                          | From display name, user-facing mail.                                                                                          |
| `SMTP_FROM_NAME_ADMIN`            | no                       | variable |                                                                                          | From display name, admin-audience mail.                                                                                       |
| `SAMPLE_SEARCH_FUZZY_THRESHOLD`   | no                       | variable | `0.8`                                                                                    | pg_trgm similarity threshold of the person facets, in (0,1].                                                                  |
| `UPLOAD_LIMIT`                    | no                       | variable | `5`                                                                                      | Attachments per sample; also baked into the admin bundle as VITE_UPLOAD_LIMIT.                                                |
| `SAMPLE_EDIT_LOCK_TTL_MINUTES`    | no                       | variable | `15`                                                                                     | Lifetime of a sample edit lock.                                                                                               |
| `EMBARGO_RELEASE_CRON`            | no                       | variable | `0 6 * * *`                                                                              | Cron pattern (Europe/Paris) of the embargo release job; every minute on the dev stack.                                        |
| `SAMPLE_LOCK_POLL_SECONDS`        | no                       | variable |                                                                                          | Admin lock-poll interval, 30 when unset, baked into the bundle as VITE_SAMPLE_LOCK_POLL_SECONDS.                              |
| `OIDC_ISSUER`                     | yes                      | variable | preproduction: `https://sso-test.earth-data.fr/realms/gaia-data`                         | SSO realm, also baked into the bundles as VITE_OIDC_AUTHORITY.                                                                |
| `OIDC_CLIENT_ID`                  | yes                      | variable | preproduction: `formaterre-igsn`                                                         | SSO client, also baked into the bundles as VITE_OIDC_CLIENT_ID.                                                               |
| `OIDC_ALLOWED_IDENTITY_PROVIDERS` | no                       | variable | `satosa,orcid`                                                                           | Accepted identity-provider aliases, comma separated.                                                                          |
| `DATACITE_API_HOST`               | no                       | variable | preproduction: `https://api.test.datacite.org`<br>production: `https://api.datacite.org` | Unset disables DOI registration: samples publish without a DOI; set, publishing answers 502 when DataCite refuses the record. |
| `DATACITE_API_KEY`                | with `DATACITE_API_HOST` | secret   |                                                                                          | DataCite credential; the api stops at boot if the host is set without it.                                                     |
| `DATACITE_DOI_PREFIX`             | with `DATACITE_API_HOST` | variable | `10.70113`                                                                               | DOI prefix to mint under, 10.70113 on the DataCite test instance.                                                             |
| `PORTAINER_URL`                   | yes                      | variable | `https://portainer.example.org`                                                          | Base URL of the Portainer the stack is deployed on.                                                                           |
| `PORTAINER_API_KEY`               | yes                      | secret   |                                                                                          | Portainer access token of the deploy user.                                                                                    |
| `PORTAINER_STACK_ID`              | yes                      | variable | `12`                                                                                     | Id of this environment's Portainer stack.                                                                                     |
| `PORTAINER_ENDPOINT_ID`           | yes                      | variable | `1`                                                                                      | Id of the Portainer environment running the stack.                                                                            |
