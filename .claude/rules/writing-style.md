# Writing style

Applies to all rules, agents, skills, docs, and prose in this repo.

- Be concise: say it in the fewest words that stay clear.
- One point is one sentence; split anything longer into separate bullets.
- No em dashes.
- Prefer a list to a paragraph: a rule is a bullet, cheaper to load and harder to half-follow.
- Never hard-wrap a sentence across lines, however long the bullet; the editor soft-wraps it.

## Editing a rule, agent, or skill

- Add a bullet to the existing list, never a paragraph beside it.
- Reword the bullet that is wrong rather than adding a second one qualifying it.
- Re-read your whole diff at the end and cut every word the file already carries.
